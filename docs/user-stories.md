# 4. User Stories
Setiap user story ditulis dengan format: Sebagai [peran], saya ingin [tujuan/aksi], sehingga [manfaat].

## Epic 1 — Onboarding
1. **US-01** — Sebagai pengguna, saya ingin login menggunakan akun Google, sehingga saya dapat mengakses layanan Maternity.id tanpa perlu membuat akun/password baru.

## Epic 2 — Katalog & Pencarian Seminar
2. **US-02** — Sebagai member, saya ingin melihat katalog seminar yang tersedia, sehingga saya dapat menelusuri pilihan seminar/pelatihan maternitas dengan mudah.
3. **US-03** — Sebagai pengguna, saya ingin memfilter katalog berdasarkan topik, lokasi, format, dan harga, sehingga saya dapat mempersempit pilihan sesuai preferensi.
4. **US-04** — Sebagai pengguna, saya ingin melihat detail lengkap seminar (deskripsi, benefit, harga, jadwal), sehingga saya dapat memutuskan sebelum berlangganan.

## Epic 3 — Langganan & Aktivasi Akses via WhatsApp Admin
5. **US-05** — Sebagai member, saya ingin memilih kategori langganan (Akses Ebook atau Akses Seminar tertentu) dan diarahkan ke WhatsApp Admin untuk checkout, sehingga saya dapat menyelesaikan pembayaran dengan mudah.
6. **US-06** — Sebagai member yang berlangganan Akses Seminar, saya ingin otomatis mendapat akses e-book terkait seminar tersebut, sehingga saya tidak perlu berlangganan terpisah untuk materinya.
8. **US-08** — Sebagai member, saya ingin menghubungi customer service saat ada kendala langganan/pembayaran, sehingga masalah saya cepat terselesaikan.

## Epic 4 — Membership, Library & Profil
9. **US-09** — Sebagai member, saya ingin mengakses e-book/materi sesuai jenis langganan aktif saya (seminar tertentu atau seluruh materi), sehingga saya mendapat konten yang sesuai hak akses saya.
10. **US-10** — Sebagai member, saya ingin menandai (bookmark) seminar/materi favorit, sehingga saya dapat menemukannya kembali dengan mudah.
11. **US-11** — Sebagai member, saya ingin mengedit profil dan informasi akun saya, sehingga data saya selalu akurat.
12. **US-12** — Sebagai member, saya ingin melihat status dan masa berlaku tiap langganan saya, sehingga saya tahu kapan harus memperpanjang.


## Epic 6 — Manajemen Mitra / Owner Seminar
15. **US-15** — Sebagai owner/mitra, saya ingin mengajukan seminar/pelatihan melalui fitur "Ajukan Seminar" (mengisi nama seminar, harga, lokasi/link, kontak, benefit, poster), sehingga kegiatan saya dapat dipromosikan di Maternity.id. yang nanti bakal diarahin ke wa


## Epic 7 — Admin Panel
17. **US-17** — Sebagai admin, saya ingin mengunggah dan mengelola e-book/materi serta mengaitkannya dengan seminar tertentu, sehingga konten pembelajaran member selalu terbarui dan terhubung dengan benar.
18. **US-18** — Sebagai admin, saya ingin menetapkan langganan tiap user (seminar spesifik atau akses ebook penuh) beserta masa berlakunya setelah pembayaran dikonfirmasi, sehingga pengguna mendapat akses tanpa perlu kode akses manual.
19. **US-19** — Sebagai admin, saya ingin mengunggah dan mengelola informasi seminar/pelatihan, sehingga katalog selalu akurat dan terkini.
21. **US-21** — Sebagai admin, saya ingin melihat dashboard keuangan (ringkasan pendapatan, jumlah langganan aktif per kategori, riwayat pembayaran), sehingga saya dapat memantau kinerja bisnis dengan mudah.

## Epic 8 — Promosi & Integrasi TikTok
22. **US-22** — Sebagai pengguna TikTok, saya ingin diarahkan ke landing page Maternity.id dari konten FYP, sehingga saya dapat menindaklanjuti ketertarikan saya.
23. **US-23** — Sebagai guest, saya ingin melihat seminar upcoming event di landing page tanpa harus login, sehingga saya tertarik untuk bergabung.

## Epic 9 — Artikel SEO & Navigasi Konten
24. **US-24** — Sebagai guest/member, saya ingin membaca artikel edukasi yang muncul di hasil pencarian internet, sehingga saya menemukan Maternity.id secara organik dan mengetahui seminar terkait di akhir artikel.
25. **US-25** — Sebagai pengguna, saya ingin menggunakan navigasi atas (top navbar) untuk mengakses Info Seminar, Ebook, dan Artikel dari halaman manapun, sehingga saya dapat berpindah konten dengan cepat.
26. **US-26** — Sebagai admin, saya ingin menulis dan mempublikasikan artikel SEO beserta tautan promosi seminar terkait, sehingga artikel dapat mendukung akuisisi pengguna baru.

## Epic 10 — Layanan Fasilitator Mitra / Tour Guide Event
27. **US-27** — Sebagai tenaga profesional (dokter/instruktur), saya ingin menekan tombol "Butuh Fasilitator Event? Hubungi Kami" di halaman kemitraan dan langsung terhubung ke WhatsApp CP Tim Maternity.id, sehingga saya dapat mendiskusikan kebutuhan pelatihan mandiri saya (venue, logistik, nakes pendamping) tanpa perlu mengisi formulir apa pun.

## Epic 11 — Testimoni Pengguna
28. **US-28** — Sebagai pengguna, saya ingin melihat testimoni peserta lain di landing page dan halaman checkout, sehingga saya lebih yakin sebelum memutuskan berlangganan.
29. **US-29** — Sebagai admin, saya ingin mengelola (menambah, mengedit, menghapus, dan mengatur status tayang) konten testimoni, sehingga testimoni yang tampil selalu relevan dan terkini.
